## ☀️ Вычеты за использование солнечных панелей

**Bonus Ristrutturazioni** - позволяет вернуть часть стоимости установки солнечных батарей в виде налогового вычета (не более 96000 € на объект).  

Ставки в 2026-2027 годах:
- `36%` для [Prima casa](./prima_casa)  
- `30%` для остальных объектов
